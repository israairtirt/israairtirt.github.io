04

Beati

An environmental app for Libya: plant trees, look after them, report problems

Prospire Foundation's first digital product, built as one Flutter app for Android, iOS and the web on a Node.js API and PostgreSQL. People find trees suited to Libya, log the ones they plant with follow-ups at 30, 90 and 180 days, report environmental problems with photos and see them on a map. An assistant answers questions, photos included, and replies in Libyan dialect when asked in it. Exact locations stay private: the public map only shows 5 km cells.

Client
Prospire Foundation, Libya
Built with
Flutter, Node.js, Express, PostgreSQL, Gemini
Tested
33 API tests, including privacy between users, and 12 app tests

Open the app

05

PhishGuard

Phishing-awareness training for small businesses

Staff look at ten realistic emails and text messages and decide which are phishing. After each answer the app shows the red flags in the message itself, from a look-alike sender to a link that goes somewhere else. A results page, a short usability survey and a dashboard with CSV export show how a team is doing.

Type
Product
Built with
Node.js, Express, SQLite. The live demo runs entirely in the browser
Security
Strict CSP, text-only rendering; the server adds scrypt and prepared statements

Freelance Platform

A marketplace where clients post work and freelancers bid

Clients post projects with a budget and a deadline, compare bids, hire, and review the work when it's done. Freelancers keep a profile and portfolio, bid, and follow their deadlines on a dashboard. It started as a C# desktop app designed with UML; the web version keeps the same model, from the password rules to each project's states.

02 · SecuritySecurity work

Two network security projects, each built around a realistic organisation: find the risks, then redesign the network to answer them.

Risk assessment · Network design

Securing a housing association's tenant data

A risk register of fifteen threats, four critical CVEs traced to the servers that carry them, a firewall and DMZ redesign, remote-access VPN, intrusion detection, and a UK GDPR position on staff using WhatsApp.
